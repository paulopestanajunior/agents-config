# Working Context

Last updated: <date>

Record only what cannot be generated or read from the code. Component
inventories, catalogs, file counts, and directory listings belong to generated
artifacts — duplicating them here guarantees they will disagree.

## Purpose

One or two sentences: what this project is, for whoever picks it up next.

## Current Truth

Facts about the project right now that the code does not state: default branch,
active environments, current release, what is deployed where.

## Current Constraints

Limits in force today — a deadline, a frozen dependency, a quota, a contract, a
migration in progress. Include why, so it can be retired when it stops
applying.

## In Flight

Work started but not finished, and who owns it.

## Blocked

What is waiting, on what or whom, and since when.

## Open Decisions

Choices not yet made that block something else. Move each to
`docs/decisions/` as an ADR once decided.

## Recent Changes Worth Knowing

Changes a returning contributor would be surprised by. Prune this as it ages;
git history is the record, this is only the headline.
